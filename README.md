# Cool Robot

A ROS2 Jazzy mobile robot simulation built using a SolidWorks-derived URDF/Xacro model.

Features:
- Four-wheel differential drive robot
- Gazebo Harmonic simulation
- LiDAR sensor simulation
- SLAM using slam_toolbox
- Autonomous navigation using Nav2
- AMCL localization

The robot can generate a map of the environment and autonomously navigate to user-defined goals.
